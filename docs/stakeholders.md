# Stakeholders

_Identificar y justificar las partes interesadas relevantes para el sistema._
_Para cada una: describir su rol y por qué es clave para el proyecto._

---
# A. Dueño del Comercio

**Tipo:** Interno

**Por qué es clave:** _Es el principal beneficiario del sistema y utiliza el bot de Telegram para acceder a información estratégica y operativa, controlar el stock y las ventas, recibir alertas y obtener reportes que faciliten la toma de decisiones._

# B. Encargado del Comercio

**Tipo:** Interno

**Por qué es clave:** _Es responsable de las actividades operativas diarias y necesita consultar rápidamente información sobre el stock, las ventas y los productos con bajo inventario para optimizar la gestión del comercio._

# C. Administrador del Sistema

**Tipo:** Interno

**Por qué es clave:** _Es responsable de mantener la infraestructura tecnológica, la base de datos y el correcto funcionamiento del sistema y sus integraciones._

# D. Desarrollador del Sistema

**Tipo:** Interno

**Por qué es clave:** _Es responsable del análisis, diseño, implementación, mantenimiento y evolución del sistema, incluyendo la incorporación de nuevas funcionalidades y la corrección de errores._

# E. Loyverse

**Tipo:** Sistema externo

**Por qué es clave:** _Es la principal fuente de información sobre productos, stock y ventas, proporcionando los datos necesarios para el funcionamiento del sistema mediante su API._

# F. Telegram

**Tipo:** Sistema externo

**Por qué es clave:** _Funciona como la interfaz principal de comunicación entre los usuarios y el Sistema SN, permitiendo el envío y la recepción de consultas, respuestas y alertas mediante el bot._

# G. n8n

**Tipo:** Sistema externo

**Por qué es clave:** _Es la plataforma encargada de automatizar los flujos de trabajo, procesar las solicitudes y coordinar la comunicación e integración entre Loyverse, Telegram y la base de datos._

# H. Comercio Cliente

**Tipo:** Externo

**Por qué es clave:** _Es la organización que adopta y utiliza el sistema con el objetivo de mejorar el control operativo, reducir los tiempos de consulta, disponer de información actualizada y optimizar la toma de decisiones._
